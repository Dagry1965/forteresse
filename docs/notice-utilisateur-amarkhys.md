## 2. Tableau de bord

Après connexion, le tableau de bord présente notamment :

- les rendez-vous du jour ;
- les dossiers atelier ouverts ;
- les factures impayées ;
- les relances à effectuer ;
- les alertes de stock ;
- les principales activités du garage.

## 3. Principaux modules

### Clients

Permet de consulter, créer et modifier les entreprises et les particuliers.

### Véhicules

Permet de consulter les véhicules rattachés aux clients et leurs informations principales.

### Rendez-vous

Permet de planifier et suivre les rendez-vous du garage.

### Atelier

Permet de suivre les dossiers, les interventions, les diagnostics et l'avancement des réparations.

### Facturation

Permet de consulter les devis, les factures, les paiements et les échéanciers.

### Stock et achats

Permet de consulter les articles, les niveaux de stock, les fournisseurs et les commandes fournisseur.

## 4. Consignes de test

Pendant vos essais :

- utilisez uniquement les données de démonstration ;
- ne communiquez pas vos identifiants à une personne non autorisée ;
- notez la page concernée en cas de problème ;
- relevez le message d'erreur exact ;
- faites une capture d'écran si possible ;
- indiquez les étapes effectuées avant l'erreur.

## 5. Informations utiles pour signaler un problème

Merci d'indiquer :

1. votre nom ;
2. la date et l'heure ;
3. la page utilisée ;
4. l'action effectuée ;
5. le résultat attendu ;
6. le résultat obtenu ;
7. le message d'erreur ;
8. une capture d'écran si disponible.

## 6. Déconnexion

Pour terminer votre session, utilisez le bouton de déconnexion dans l'interface.

Fermez ensuite l'onglet du navigateur si vous utilisez un ordinateur partagé.
